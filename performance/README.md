# 周期 5 压测

使用 Apache JMeter 5.6.3 的非 GUI 模式。纯数据库路径与 Redis 预扣路径必须使用相同的
线程数、升压时间、持续时间、连接池配置和测试 SKU。每条路径预热一次，再正式运行至少
三轮并取中位数，同时记录吞吐量、P99 和错误率。

计划通过属性切换路径：

- 纯数据库：`-Jpath=/api/orders -JexpectedCode=201`
- Redis 预扣：`-Jpath=/api/orders/redis -JexpectedCode=202`

订单号由线程号和迭代次数生成。每轮应使用不同的 `-JbaseOrderId`，避免唯一键冲突。
压测前后使用项目脚本重置测试 SKU、清理基准订单并检查异步命令是否全部落库。

Redis 路径返回的是“已接受并等待落库”，数据库路径返回的是“订单和库存已经提交”。
报告必须明确两者确认语义不同，不能把 Redis 接受响应描述成同步落库完成。
