# V2.1 订单操作增量验收（2026-09-24）

## 完成范围

- `POST /api/orders/{orderId}/cancel` 仅作用于当前登录用户的待支付订单。订单条件更新先与支付竞争，再由已有补偿任务幂等释放库存；失败保留 `PENDING_COMPENSATION` 等待重试。重复取消返回已取消，已支付订单返回冲突，他人订单返回 404。
- 库存预占成功后如果订单状态条件更新未命中，会读取持久化状态：并发重复创建已标记 `RESERVED` 时直接返回成功，只有取消已赢且库存待补偿时才释放，避免误释放有效订单。
- `POST /api/payments/orders/{orderId}/mock-success` 仅供本地演示。Payment 经内部接口读取订单归属，使用稳定交易号调用原有支付确认路径；Gateway 校验 JWT、剥离客户端内部令牌并给 Payment 路由重新注入，直连 Payment 不能伪造用户头。
- 订单详情页展示“取消订单”和“模拟支付”。模拟支付不会产生真实扣款，支付成功后仍由 Order Outbox 异步通知 Inventory 确认库存。

## 验证

- 微服务 Reactor 119 项测试通过，0 失败、0 错误、0 跳过；覆盖取消归属、支付竞争、预占晚到、并发重复创建、模拟支付归属、稳定交易号和直连端口防护。
- Vue 生产构建通过，38 个模块转换。
- 本机 Gateway、Order、Inventory、Payment、Commerce 五个健康端点均为 `UP`。
- 同一测试账号完成两笔订单：第一笔模拟支付返回 `ACCEPTED`，订单为 `PAID`；第二笔主动取消返回 `CANCELED`，订单和预占状态分别为 `CANCELED`、`COMPENSATED`。直连 Payment 并伪造 `X-User-Id` 返回 HTTP 401。
- SKU 1002 验收前可售 99、锁定 0；一笔支付和一笔取消收敛后可售 98、锁定 0。取消订单的库存已释放，已支付订单消耗 1 件。

## 边界

Payment 当前仍没有独立的持久化支付单与回调记录；模拟支付只是本地演示入口，不是第三方支付集成。Outbox 的库存确认是异步的，模拟支付响应时锁定库存可能尚未归零。尚未做浏览器逐页手工验收、多实例竞争、外部支付渠道或生产网络隔离。
